# AI do kwalifikacji zapytań

Pierwszy szablon portfolio.

## Cel
Odbiera mail lub formularz, rozpoznaje temat, priorytet, klienta i przypisuje sprawę do właściwej osoby.

## Plan katalogów
- `docs` - wymagania, scenariusze, opis procesu
- `frontend` - widok demo / panel
- `backend` - logika kwalifikacji i routing
- `integrations` - mail, formularze, CRM, webhooki
- `assets` - grafiki, screeny, mockupy

## MVP
- `app/index.html` - gotowe demo w przeglądarce
- Otworz plik bezpośrednio w przeglądarce lub przez prosty serwer statyczny
